# Issue tracker

Linear: team `Bridgexconnect`, project `Folio Voyage — Atlas Platform`. Issue keys are `BRI-<n>`.

**Read-only for agents.** Agents in this repo may read issues (via the Linear MCP, if the session has it). They never create, edit, comment on, label or close issues: the planning chat owns Linear. If a skill wants to publish tickets or apply labels, stop and report what it wanted to create.

Specs and plans live in the repo, not in the tracker: `docs/specs/` for specs, and `docs/superpowers/plans/` for plans and epic maps.
